# Scream UI Component Gallery

This is the interactive showcase for the `@ghchinoy/lit-audio-ui` library. It demonstrates how to use the components in a realistic, modern web application environment.

## Key Features
* **Full Component Showcase:** Every atom and molecule in the library is demonstrated here.
* **Theming Workbench:** Real-time CSS variable and Material 3 design token customization.
* **Complex Orchestration:** Examples of `ui-audio-provider` and `ui-speech-provider` coordination.
* **Responsive Design:** A mobile-friendly layout using standard CSS flex and grid.

## Development

This sample is part of the Scream UI monorepo.

### 1. Build the library first
From the monorepo root:
```bash
npm run build -w @ghchinoy/lit-audio-ui
```

### 2. Run the gallery
From this directory:
```bash
npm run dev
```

## Production Build
```bash
npm run build
```
The output will be in the `dist/` directory.
